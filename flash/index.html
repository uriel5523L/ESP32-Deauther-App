⚡ Flashear ESP32

Conecta tu placa por USB y pulsa el botón. Soporta ESP32 y ESP32-S3 (el flasheador elige el bin según el chip detectado). Usa Chrome/Edge en escritorio o Android, vía HTTPS.

⚠ Antes de flashear

  1. El firmware trae login. Tus credenciales están en firmware/include/secrets.h (usa secrets.h.example).
  2. Si flasheas este bin tal cual, lleva las credenciales con las que se compiló. Para poner las tuyas, edita secrets.h y recompila.
  3. Placa por defecto ESP32: esp32doit-devkit-v1. Para S3/C3 cambia el env en PlatformIO.
  4. Si tu placa no entra sola en modo flash, mantén pulsado BOOT mientras se conecta.

En ESP32-S3, WiFi y BLE comparten el radio: el firmware apaga el AP mientras usas BLE para que sea estable.
