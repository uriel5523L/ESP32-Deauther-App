ESP32-Deauther App

Controla tu ESP32 por WiFi o Bluetooth (BLE) desde el móvil. Con login.

⬇ Descargar APK (Android) 📦 Ver código fuente

📡 Conexión WiFi

Conéctate al AP ESP32-Deauther y controla todo por HTTP con token de sesión.

🔵 Bluetooth BLE

Escanea y empareja por BLE (Nordic UART). Funciona en Android e iOS.

🔐 Login

Credenciales admin / deauther protegen la Web UI y la API JSON.

Cómo usarla

  1. Sube el firmware (firmware/) al ESP32 con PlatformIO.
  2. Instala el APK en tu Android (permite orígenes desconocidos).
  3. Abre la app y elige WiFi o Bluetooth.
  4. WiFi: IP 192.168.4.1, usuario admin, password deauther.
  5. Bluetooth: pulsa “Escanear”, elige ESP32-Deauther, escribe el password.
  6. Escanea redes, selecciona una, elige un Reason code y pulsa Deauth.

Nota: para iPhone no hay APK; necesitas una Mac con Xcode y flutter run. “Deauth all” apaga el WiFi del ESP32: para pararlo, resetea la placa.
